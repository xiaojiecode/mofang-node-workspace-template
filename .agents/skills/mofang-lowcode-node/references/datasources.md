# AI 配置数据源

先查 `lowcode catalog --id source`、绑定和脚本目录，取得当前 schema。确定接口地址或连接身份、查询/写入语义、参数来自哪个表单或节点、响应数据路径、触发时机、失败显示和认证来源。资料已有就直接沿用；缺认证能力要明确告知，不能用样本冒充接通。

数据源有 local、host、http 三类。节点公开投影使用 hostKey=nodeView，配合依赖触发在节点变化后刷新；结果可用 transform 脚本转换。脚本输入为 `{data,params}`，直接读取 input.data 时不需要虚构依赖。

HTTP 支持完整 URL 或宿主登记连接。连接凭据由宿主提供；页面 JSON 仅存连接身份及业务映射，不保存 token/password。完整 URL 不自动附带平台登录态，也不能绕过浏览器跨域。

模板交互预览默认只模拟本地和宿主数据，HTTP 请求会明确报未配置。配置 HTTP 不等于已经联通；可以先用带来源标识的 local 样本验证映射，再按已有授权在目标环境联调。写入请求只在显式事件触发，不挂在设计渲染或初始化上。

修改 source 后一并核对消费它的表格、选项、加载/失败/空态，以及响应迟到、页面离开和依赖变化的取消语义。不能把整个响应硬编码成业务数据，也不要从组件内部状态读取数据。
