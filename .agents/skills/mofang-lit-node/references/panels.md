# 面板容器与候选

## 按宿主容器布局

settings只负责设置内容；工作流设置外壳提供导航与策略，宿主保有统一草稿保存/取消。business处于有限高度上拉抽屉，标准或 full-panel 均按原型提供已确认的业务交互，不自动追加动作和状态区；全屏由用户显式切换，不能把浏览器视口当默认画布。内容滚动归属清楚，重要动作不能仅在滚动不可达底部。

## 必须人工事件的页面引导

先读真实动作声明和guard。动作入口和参数选择按原型与用户确认的交互实现，不自动添加 finish 或通用动作按钮；缺少结束生产或审核入口时列为待确认缺口。关闭抽屉和 endReview 不代替 finish。零结果、不选择、失败与unknown分别显示原因和下一步。

动作accepted、applied、任务成功和节点成功分开。applied后仍可能等待候选审核；rejected/failed保留选择并显示原因；回执未知先查记录，不自动再写。候选update/remove/release用真实ID/修订，历史已流转快照只读。接线见[SDK](sdk.md)，整抽屉见[边界](full-drawer.md)。
